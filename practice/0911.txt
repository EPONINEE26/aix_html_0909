json 이 xml 보다 용량이 조금 작다. 요즘은 json을 많이 사용.
호환되는 포맷이 많음. 

파이썬은 json을 파악하지 못하기에 딕셔너리 형태로 변환해서 처리를 함
json 데이터 전송 방식 
파이썬 / 자바 / C 등등 서로 데이터를 전송할 때 json으로 전송하여 각각의 프로그램에서 처리 

<script> 는 맨 위쪽이나 맨 아래쪽에 입력하는 것이 표준이다. 

required 입력을 꼭 해야만 처리진행이 가능 

수정할 수 있는 기능이지만, 두 가지의 차이점 
disabled 아에 전송 불가 
readonly 전송은 가능 

style 의 다른 말 css 
CSS(Cascading Style Sheets)는 웹페이지의 뼈대를 이루는 HTML 문서의 색상, 글꼴, 레이아웃 등 디자인과 시각적 요소를 꾸미는 스타일 시트 언어입니다
csss 는 맨 위에서부터 확인하고 처리하기에 무조건 맨 위에 입력하는 것이 좋다.
전체 선택 * (별표) 

태그 : 해당되는 태그 모두 지정할 때 
아이디 : 1개만 지정할 때 가장 강력함 (# 삽으로 지정)
클래스 : 여러 개를 지정할때 (. 점으로 지정) 

아이디 > 클래스 > 태그 이런 식으로 처리 

!important 우선 적용하라는 의미 
표준이 안 된 것들은 무조건 접두사를 입력해야함
