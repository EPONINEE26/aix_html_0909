이탤릭체 쓰는 이유는 강조
em i 
strong
모두 강조의 기증 

shadow 
- 로 지정을 하면 위쪽으로 그림자 생성 

text - indent 속성은 들여쓰기 
margin: 0 auto; 이미지 중앙 정렬  auto 는 양쪽 1/2만큼 정렬

contain : 한 방향으로 이미지 모두 다 보여줌 
cover : 전체 커버 

background-position: 이미지 위치 변경 
image, repeat, attachment, postion  background 한 줄에 다 같이 쓸수 있음 */ 
background: url('images/back1.jpg') no-repeat fixed 30px 200px; 

background-size
background-clip
background-origin 
이건 따로 써야함 

background: linear-gradient 최신 버전에서는 어느 정도 기준이 생겼기에 접두사 안 붙여도 됨 
background: linear-gradient(90deg, blue, white); 각도 90도 
background: linear-gradient(to right bottom, blue, white); 방향 오른쪽 

background: radial-gradient (원형 그라데이션) 

ul{display: flex;} 옆으로 출력되게 함 사각형 정렬 (블럭박스를 정렬할 때 사용) 

공간이 없을 경우 마지막 칸은 밑으로 떨어짐 

space - between
flex start 

.c1{width: 588px; height: 536px; border: 1px solid black;}

span은 너비 높이를 바꾸어도 적용이 안 됨 
display:block ; 밑으로 출력되게 함 
display:inline-block ; 인라인이면서도 블록 기능

display:nome 요소를 숨기고 싶을 때 사용, 사이즈를 줄여서 볼 때 항목이나 요소를 숨길 때 사용 

inline 은 너비 높이 지정 불가 옆으로 출력 
block 너비 높이 지정 가능 밑으로 출력 
inline-block 인라인이면서 블록요서 기능 

iframe 웹 문서 안에 다른 문서 삽입  새로운 페이지를 넣을 때 사용. 사이트 내 사이트 삽입 
대부분의 기업들은 연결을 거부하고 있음 (범죄에 연결이 될 수 있을 수 있기에) 

H.264/AVC 영상 관련 사용시 (무조건)
control 재생버튼 생성
auto muted 자동 재생 
loop 무한 반복
